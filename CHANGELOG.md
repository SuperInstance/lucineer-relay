## [0.1.0] - 2026-08-05

### Added
- Cloudflare Durable Object relay and job queue for the Slackwater build pipeline
- SQLite-backed Durable Object for job state management
- Public endpoints for Roblox client traffic
- Authenticated internal endpoints for the Python processor
- R2 storage for MOLT trajectory data
- 43 tests covering relay, queue, and authentication
